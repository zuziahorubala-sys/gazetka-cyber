# Gazetka Cyber

Codzienny przegląd newsów o cyberbezpieczeństwie (PL/EN) na podstawie wpisów z X od wybranych kont o cyberbezpieczeństwie.
Każde wydanie zawiera 10–15 artykułów o najważniejszych sprawach dnia oraz 50–100 krótkich newsów w kategoriach.

- `gazetka-cyber-RRRR-MM-DD.html`: kolejne wydania
- `index.html`: najnowsze wydanie i archiwum (strona główna GitHub Pages)
- `_konfiguracja/wzor-wydania.html`: wzór wyglądu wydania
- `_konfiguracja/extract.js`: skrypt zbierający wpisy ze strony wyszukiwania X
- `_konfiguracja/publikuj.ps1`: odświeża `index.html` i wysyła zmiany na GitHuba

Wydania przygotowuje automatycznie Claude (zadanie „Gazetka Cyber” w aplikacji Claude). Przed działaniem warto sprawdzić szczegóły w podlinkowanych źródłach.
